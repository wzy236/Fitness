# 减脂塑形健身计划

## 计划概览

| 项目 | 详情 |
|------|------|
| 目标 | 减脂瘦身 |
| 训练水平 | 中级 |
| 训练天数 | 每周 5 天 |
| 训练模式 | 三分化（推 / 拉 / 腿） |
| 训练地点 | 健身房（含有氧设备） |
| 计划周期 | 12 周 |

## 三分化结构

```
推（Push）— 胸 + 肩 + 三头肌
拉（Pull）— 背 + 二头肌
腿（Legs）— 股四头 + 腘绳肌 + 臀 + 小腿
```

## 每周安排

| 星期 | 训练 |
|------|------|
| 周一 | 推 A（胸肩三头）|
| 周二 | 拉 A（背二头）|
| 周三 | 腿 A（股四 + 腘绳 + 臀）|
| 周四 | 推 B（变式）+ 有氧 |
| 周五 | 拉 B（变式）+ 有氧 |
| 周六 | 主动恢复（低强度有氧 / 拉伸）|
| 周日 | 完全休息 |

## 文件目录

```
workouts/

├── pull_a.md       拉 A 训练
├── legs_a.md       腿 A 训练
├── push_b.md       推 B 训练
├── pull_b.md       拉 B 训练
└── cardio.md       有氧方案
nutrition.md        营养指南
progress.md         进度追踪模板
```

## 关键原则

1. **热量缺口**：减脂期间保持每日热量缺口 300–500 kcal
2. **蛋白质优先**：每公斤体重摄入 1.6–2.0g 蛋白质，保护肌肉
3. **渐进超负荷**：每 1–2 周适当增加重量或组数
4. **充足睡眠**：每晚 7–9 小时，促进恢复与脂肪代谢
5. **训练后有氧**：力量训练结束后进行 HIIT 或稳态有氧效果更佳

## 注意事项

- 每次训练前做 5–10 分钟热身
- 训练中组间休息：力量动作 60–90 秒，有氧动作 30–45 秒
- 如有关节不适，立即停止并调整动作
