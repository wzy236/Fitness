Supabase 数据库配置

免费、永久、无需后端。数据存在云端 PostgreSQL 数据库，任何设备都能访问。

配置步骤（5 分钟）

  1. 打开 supabase.com 注册免费账号，新建项目
  2. 进入项目后，点左侧菜单 SQL Editor，粘贴下方 SQL 并执行：
CREATE TABLE workout_logs (
  id        BIGSERIAL PRIMARY KEY,
  date      DATE NOT NULL,
  exercises JSONB DEFAULT '[]',
  duration  INTEGER DEFAULT 0,
  notes     TEXT DEFAULT '',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE workout_logs ENABLE ROW LEVEL SECURITY;
CREATE POLICY "allow_all" ON workout_logs
  FOR ALL TO anon USING (true) WITH CHECK (true);
  1. 点左侧 Project Settings → API
  2. 复制 Project URL 和 anon public key，分别粘贴到上方两个输入框
  3. 点保存，再点测试连接
