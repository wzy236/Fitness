Google Sheet 配置

需要先设置 Google Apps Script 链接，才能保存和读取运动记录。 查看配置教程 →

如何获取 Apps Script 链接

  1. 打开 Google Sheets，新建一个表格
  2. 点击菜单 扩展程序 → Apps Script
  3. 删除默认代码，把 Code.gs 里的内容全部粘贴进去
  4. 点击 部署 → 新建部署
  5. 类型选 Web 应用，执行身份选「我」，访问权限选「所有人」
  6. 点击部署，复制生成的链接，粘贴到上方输入框
