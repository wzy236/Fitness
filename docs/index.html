GitHub 存储配置

运动记录会直接保存到你的 GitHub 仓库，免费、永久、有版本历史。只需要一个 Personal Access Token。

如何获取 Token（3 步）

  1. 打开 GitHub → Settings → Fine-grained tokens → New token
  2. 填写名称（如 fitness-log），在 Repository access 选 Only select repositories，选 Fitness
  3. 展开 Repository permissions，找到 Contents，改为 Read and write
  4. 点击 Generate token，复制生成的 token，粘贴到上方输入框

⚠️ Token 只保存在你的浏览器本地，不会上传到任何服务器
